**Student Performance Analytics System**

**Student:** Yuvraj  
**Course:** Python with AI

### 2. Objective

The project was created to build a Python-based student performance analysis system. It reads student records, processes marks and attendance, and produces meaningful performance information.

The system calculates total and average marks, assigns grades, identifies pass/fail students, performs subject-wise analysis, identifies top performers and calculates overall class performance.

---

### 3. Technologies Used

- Python
- NumPy
- Pandas
- CSV dataset
- GitHub for project submission

---

### 4. Dataset Description

The project uses a CSV dataset containing 20 student records.

Important fields include:

- Student ID
- Name
- Department
- Python marks
- Pandas marks
- NumPy marks
- Data Analysis marks
- Attendance

The dataset is stored in `students.csv`.

---

### 5. Implementation

#### Step 1 - Prepare Dataset

A CSV dataset with 20 realistic student records was created.

#### Step 2 - Read the Data

Pandas `read_csv()` is used to load the student dataset into a DataFrame.

#### Step 3 - Process the Data

NumPy is used for numerical operations such as:

- Sum of subject marks
- Mean/average calculations

Reusable functions are used for:

- Total and average calculation
- Grade assignment
- Pass/fail calculation
- Subject-wise analysis
- Finding top performers

Loops and conditions are used where iteration and decision-making are required.

#### Step 4 - Perform Analysis

The system answers practical questions such as:

- Which student has the highest average?
- Which student has the lowest average?
- Which subject has the best average?
- How many students passed?
- How many students failed?
- What is the overall class average?
- Which students are the top performers?
- What is the average attendance?

#### Step 5 - Final Output

The program prints the analysis in a readable format and saves a processed report as `student_performance_report.csv`.
